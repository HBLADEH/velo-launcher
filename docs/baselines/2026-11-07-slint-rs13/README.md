## 采集方式

[rs13_visual.rs](../../../rust/examples/rs13_visual.rs) 使用实际 Slint 页面与控件、固定合成数据，分别编译 Software/FemtoVG 专用采集程序；每种包含深浅主题各 17 个场景，共 34 张。它不打开业务 Store，不扫描磁盘，不注册热键/托盘，不执行 Shell、持久化、下载或安装。文件路径固定为虚构的 `C:\VeloFixture`。

```powershell
./scripts/capture-rust-visual.ps1 -OutputDirectory .reasonix/rs13-my-capture
# 静态图册整理需要 Python + Pillow（只用于开发工具，不进入应用依赖）
python scripts/summarize-rust-visual.py .reasonix/rs13-my-capture .reasonix/rs13-my-gallery
```

输出目录须全新。入口检查锁定原生工具链，构建前固定 UI/采集源码指纹，采集结束再次核对；保留 exe 和图片 SHA。每个场景先更新组件，下一次 250 ms tick 才调用 `Window::take_snapshot`，PNG 编码在容量为 2 的后台队列完成。关闭减少动画用于录像的工作另行执行；本轮为稳定截图而开启减少动画，不能从 250 ms 采集间隔推导帧耗时。

截图来自渲染器组件快照，像素尺寸单独记录；不等价于显示器扫描输出、DWM present、原生候选框或同轮 Wails 的截图。专用采集 exe 的身份独立于 RS-12 冻结业务程序，不将结果改标为其资源样本。

## 源码审查发现的视觉差异

| 项目 | 源码证据与判断 |
| --- | --- |
| tile 与内容进入 | Slint 保留 360 ms/24 ms tile 入场，内容 240 ms/5 px；网格结果关闭 tile 入场。时长常量存在，实际曲线/帧未验 |
| 跨行入场顺序 | Slint `HomeSection` 传入 `order=index`，延迟按项累加；旧版以 `%6` 按列重置。单行截图无法验收这一差异，需跨行录像与取舍 |
| hover/按压/选中 | tile 上移、图标缩放、按压 0.96 和列表 140 ms 选择过渡存在；Wails 的 CSS 阴影/滤镜与 Slint 绘制需同轮像素比较 |
| 业务设置页切换 | `app.slint` 的 220/100 ms 淡入淡出与 280 ms 位移仅用于非业务 appearance 面板；完整业务 `SettingsPanel` 仍直接切换 visible，不能宣称沿用该动效 |
| 装饰动效 | Wails 的齿轮 35° 旋转、扫描 1 s 旋转、录制 1.2 s 脉冲在当前 Slint UI 未见对应实现；保留为明确差异，尚未批准删减 |
| 减少动画 | 正常业务模式从 `preferences::reduced_motion()` 读取 Windows 偏好；本轮截图主动关闭动画，不验证运行中系统切换或隐藏后的帧活动 |
| 视觉门槛 | 没有同轮相同 fixture 的原生 Wails 对照，不宣称 ≤2 逻辑像素或视觉一致；两种 Slint 的像素差异仅供定位，不自动判失败/通过 |
| 空固定组 | 两种渲染器的空固定组快照均出现顶部额外空白；需核实模型缩短时的滚动位置保留，尚未定位为业务缺陷或批准为视觉取舍 |
