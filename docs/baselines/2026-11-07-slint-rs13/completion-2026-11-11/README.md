# RS-13 视觉补验与修复

最新进展见[布局、原生动画与物理输入续验](layout-followup/README.md)。下文保留首轮构建及当时未通过结论，不能作为后续修复构建的当前状态。

2026-11-11（北京时间）。本轮完成两种当前 Slint 构建的自动回归、**104 张组件静态截图、26 段组件动效记录和三候选的局部原生对照**。RS-13 仍为**进行中**：同轮对照已发现明确布局/控件差异，≤2 逻辑像素门槛没有通过；完整原生动画及当前构建的物理 DPI/IME 复核尚未完成。没有选择默认渲染器或放行 G4。

## 本轮修复

- 首页短内容的容器补齐显式原点。Slint Flickable 会把未指定位置的短子项居中；空固定组因此出现额外顶部留白。现在空固定、空常用、多行首页的标题保持同一位置，深浅主题与两个渲染器的 **12 项独立像素回归通过**，见[回归记录](heading-regression.json)。原截图仍保留在上级目录。
- 首页 tile 的延迟改为每列 `index % 6 × 24 ms`；原来的全局累加会令第二行额外延迟。逐帧检查在各自约 80/81 ms 快照上比较相同列两行的归一化进入进度，差分别约 0.02/0.05；这只验证组件节奏，没有由低频采样推导精确显示器时长。
- 完整业务设置和导入页接入进入 220 ms 透明度/280 ms 位移、离开 100 ms 透明度过渡。进入第一帧点击回调和关闭时首页点击回调均检查通过；关闭的面板禁用子控件与滚动，搜索焦点立即恢复，避免退出过渡截获点击。
- 补齐设置齿轮 hover、扫描旋转、录制脉冲，以及空常用组提示。Slint Software 1.18.1 的渲染器明确返回 `supports_transformations=false`，原生图像旋转会静止；新增工具将**现有 Fluent SVG 的原 Bézier 控制点**转为可旋转 Path，两种 renderer 使用同一轮廓，没有新增依赖或位图序列。来源与生成结果由 `generate-rust-rotating-icons.py --check` 核对，沿用 MIT 许可。

Go 1.25.6 的 `verify.ps1 -SkipBuild` 通过，包括共享采集工具回归、26 项前端测试、lint/类型检查/构建、Go vet/test。结果和原始日志 SHA 见[verification.json](verification.json)，两个产品 exe、构建回执及全部构建输入见[build-identities.json](build-identities.json)。新增视觉入口的错误 exe SHA、变化 seed、正式数据目录三项[拒绝检查](tool-guards.json)均在创建运行目录或启动程序之前拒绝。当前 Software/FemtoVG exe SHA 分别为 `60A671F568EF9BE8DF32DBDB5FED4CBF50A86F186137CCFBC16899DA965F680A` / `068B44441E8335BB3035CE4000435154986DD93FD293E7439758AD466E1FFFA1`。

这些是 RS-13 改过 UI 的新构建，**不是 RS-12 冻结测量 exe**。RS-12 的资源/延迟数值保持原身份；本轮没有把原测量改标为新程序的内存或 CPU 结论。

## 同轮原生对照

使用 RS-12 第四版合成 1000 项 seed 的独立副本，固定四项，禁止自动更新和登录启动；每个主题的三个候选初始配置/应用库/历史/索引 SHA 相同，实际扫描后仍观察到 1000 项。Wails 使用原冻结的 v0.9.11 `latencyprobe` exe `14FB81E432B0543A32DC5E7B1698596A15BB5824136BA045C0AFBB36201B7AFA`，Slint 使用上述当前验证构建。Wails 与 Slint 实例/目录隔离、串行运行；程序身份和适用边界见[原生观察](native/observations.json)。

本轮保存 **52 条原生场景记录**，含一次未正常完成的 Software 会话；公开 43 张原始 JPEG。三候选均补采浅/深首页和常规页；浅色七设置页、列表、空结果、自定义应用、候选项菜单、原生选择器及取消由本轮多个会话覆盖。Software 快捷键/外观/下拉截图来自最初中断会话，保留为局部观察，未计为完整通过会话。两份当前 Slint 的许可区可滚动到底并见 AboutSlint。

各候选原生 HWND 记录均为 **96 DPI**，主页/设置 **640 × 660**；列表实际为 640 × 588、空结果为 640 × 210，由截图及状态日志分别留证。原生截图是 Computer Use 返回的原始 JPEG；鼠标附近的蓝色强调来自采集工具，不能作为产品光晕或布局的一部分。选择器可能包含本机目录，原件仅保存在本地，不发布其像素；索引页底部个人路径提示同样不发布。

[浅色原生对照](native/comparison-light.png)将原始 640 × 660 JPEG 解码后并排排列，未缩放单张界面；它是审查总览，不是无损客户区采集或精确容差判据。

## 未通过和仍待验证

- **整体几何未通过。** 当前设置页标题/正文起点、表单横排与旧版竖排、输入宽度、页签/按钮及底部布局差异超过原计划容差；例如常规页的“最多显示结果”在 Slint 与标签同排、占大部分行宽，Wails 在下方且约 150 像素宽。需要继续还原；不能把原生控件替换视为已批准的视觉取舍。
- **视觉/行为差异未签收。** Slint 使用平面背景与标准控件，旧版有层次背景、阴影、外观预览及下拉说明；首页自定义入口/底部键盘提示、搜索网格图标尺寸、固定操作入口及系统快捷展开行为仍不一致。缺失合成目标的右键菜单中，Slint 的目录/管理员动作禁用，Wails 仍提供动作。没有用不存在的目标实际启动，也没有据菜单外观证明权限链路相同。
- **原生覆盖尚不完整。** 本轮未录制同轮 Wails 的对应动画，未完成全部深色原生页、搜索网格、空固定组、长名称/路径与所有确认提示的原生矩阵，不能将组件图册冒充这些场景的原生对照。
- **当前构建的物理复核未新增。** 本轮只观察 96 DPI 和自动化 Unicode 文本；100/125/150/200%、混合 DPI 与微软拼音物理候选框/选词/翻页/取消继续按[续验步骤](../../../rust-slint-rs13-testing.md)执行。RS-03/06/12 旧身份的实机记录保留，不改标为本轮新 exe。
- **没有新的成本取舍结论。** 新增旋转路径/面板后未重采完整产品 CPU/帧/常驻矩阵，不宣称原预算自动适用于新构建。后续视觉还原或明确取舍应附同场景成本数据，RS-14 再选 renderer。

## 失败保留和清理

第一次原生 Wails 普通模式没有暴露可操作窗口，正常退出；诊断模式可操作，期间与静态采集窗口重叠的一张快捷键页截图判无效并重采。Wails 的诊断参数禁用失焦隐藏，Slint 的同名参数**只增加日志**。此前启动器说明对这一点的混同已纠正。

Software 首次展开主题下拉后工具报告检测到窗口输入，之后绑定不可用；日志有失焦隐藏与一次托盘呼出，未擅自归因为产品崩溃或用户操作。该进程退出码 -1，保留原包装器的 `ForcedCleanup=false` 及另行生成的真实强制清理记录；综合观察正确标成强制清理，只删除这个已核对 PID/创建时间的测试托盘，再终止测试进程。后续同 exe 会话通过正常事件循环退出。原异常不能由成功复验抹掉。

首轮动效采集的减少动画切换时机造成懒求值属性未进入动画；修正夹具的预热后才采到有效入场/hover。首轮 Software 图像旋转无像素变化促成 Path 修复。一次 Debug 编码超过容量 2 的队列而明确失败、一次标题回归误包含变化的滚动条而失败，原记录均保留；最终只检查标题区域，两个 renderer 的修复构建通过。没有删除失败原件或扩大队列来掩盖问题。

最终六份有效深浅原生会话均退出码 0、无强制结束；之前的 Software 强制清理独立列示。所有本轮 Velo/采集实例、所属 WebView、托盘、热键和实例锁按[清理记录](cleanup.json)复核。正式文件的前后 SHA 只覆盖记录的哈希括号，不声称覆盖第一次读文件之前的整个会话。工作区既有改动保留，没有提交、推送、安装或修改登录项。
