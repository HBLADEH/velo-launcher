## 触发与修复

在现有已保存配置中使用自定义快捷键，令默认 Alt+Space 被占用，缓存索引使用 10000 个合成条目延长异步加载。原 Software Release 在尚未读完配置时按默认键注册失败决定显示窗口；稍后保存键成功注册，也没有恢复后台启动语义。原始失败报告和 exe 身份单独保留，旧证据不改标为新构建。

正常业务启动现在等后台数据快照和实际快捷键注册结果就绪，再做一次首次显隐决定。首次不预注册默认键，显式 `--hotkey` 仍优先；固定样例和原测量入口沿用原流程。读取失败则显示窗口与错误，保留未来/损坏文件保护，后续显隐和设置重绑仍按原生命周期处理。

新增 `rust/examples/rs11_startup.rs` 启动真实 Release 副本，覆盖中文/空格目录、独立实例、独立数据和后台参数。检查窗口实际可见状态、诊断顺序和原文件指纹；原生热键服务验证注册冲突，无键盘注入。结束时只删除所属测试托盘图标并回收测试 PID，区别于正常用户退出。
