# Velo v0.10.0 发行验收

2026-11-16，用户确认界面调整并授权以精确标签 `v0.10.0` 发布，引导 Go 用户迁移。新安装默认快捷键保持 Alt+Space，迁移不重置已有快捷键。

本目录在发行准备过程中创建。最终构建身份、安装与更新验证结果完成后记录，不将前轮开发快照或 0.1.0 验收改标为本轮结果。此前 UI 开发检查见 [名称/托盘/底栏](../2026-11-16-velo-0.10.0-ui/README.md)与 [Space 按键](../2026-11-16-velo-0.10.0-space-keycap/README.md)。

发行提供两种 Rust 系统安装器，以及默认 Software 安装器的 Go 兼容名称；免安装版和未核验旧构建按发布说明手动迁移。所有安装测试只在指定的 Windows 10 隔离客户机运行，宿主机正式程序和数据不用于测试。
