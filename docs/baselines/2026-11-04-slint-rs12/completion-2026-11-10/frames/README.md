## 原生采集与校验

`rs12-frame-observer.cpp` 使用系统 D3D11/DXGI Desktop Duplication，分别记录桌面合成帧的 `LastPresentTime`、GPU 读取完成时间及 QPC/UTC 时钟括号。只观察指定 PID/创建身份的 HWND 内缩客户区；隐藏、遮挡、跨出当前显示器、旋转输出和不支持的格式不接收为有效裁剪。低级 hook 仅保存固定 A、Backspace、Esc 和 Alt+Space 的时间、修饰键及注入标志，不保存查询文本、其他按键或窗口标题，不注入输入或激活窗口。小批量位图只留本地，设文件数与 128 MiB 预算，**本公开目录没有产品/桌面截图**。

观察器只用于验证，不增加产品依赖。使用仓库锁定 MSVC 14.50.35717 / SDK 10.0.26100.0，以 `/W4 /WX` 构建；[构建身份](observer-identity.json)记录 exe 与源码 SHA-256。

自绘、不激活的校验窗口依次绘制带二进制序号的图案，并自行移动/缩放；检查首次观察到的每个序号，不能把重复桌面帧算成新绘制。最终构建的[原生回归](native-calibration-verification.json)覆盖 4 次几何观察、3 种裁剪尺寸与 137 个帧，无图像输出；每个接受的帧时间均不早于其几何观察时间。时钟/绘制到桌面合成范围见[校验汇总](native-calibration-summary.json)，这些是采集器自校验，不是 Velo 帧率或首次可输入验收，也不提供显示器像素发光时间。

汇总器拒绝帧时间晚于读取时间、异常时钟映射、PID 创建身份不符和报告覆盖。整段时钟不稳定时默认拒绝；显式选择稳定区间必须从原始时钟括号开始，区间外物理按键保留为无效，不静默删除。旧几何采集默认禁止作为产品帧证据，仅能用显式诊断参数查看开发记录。相关错误边界和真实 PNG 解码测试已接入 `verify.ps1`。

## 开发失败保留

首次 Software 捕获期间 UTC 相对 QPC 跳变约 -1142.958 ms，整段映射被拒绝。21 轮按键均在跳变约六分钟后的稳定时段，显式区间复核通过且没有与离线数据准备重叠；[开发复核](software-review.json)保留先前算出的区域变化上界，但后续发现旧观察器的几何竞态，**这些数字整体排除出产品性能验收**。原采集窗口到 900 秒上限结束，`Completed=false / Timeout` 保持原样，程序随后正常退出码 0。

FemtoVG 1000 项实测暴露另一个采集缺陷：窗口高度变化时，按新几何裁剪的桌面帧可能仍是旧帧，保存图像中混入窗口后方内容。用于定位“退出”的标注图因此无效，已排除；原图仅保留本地失败证据，不再展示或用于产品结论。修正后的观察器在几何变化时丢弃旧帧，要求桌面帧时间晚于几何观察，并在 GPU 读取后再次核对客户区、可见与遮挡状态。全新构建与移动/缩放回归通过，但还需全新产品录制才能验收，不能回填旧帧的正确性。

首版 1000/10000 夹具的图标 URL 也未满足现有 32 位十六进制缓存命名，实测显示回退字母图标，原条件保留。第二版在预检被拒绝、未运行；第三版由 SHA-256 派生合法缓存名，真实解码、1000/10000 数量和唯一 ID 测试通过，[准备身份](fixture-preparation.json)明确它尚未实测。不得将回退图标条件改标为第三版资源。

## 物理交互结果

Software 使用原 RS-12 seed 与冻结 exe，新会话有 **21 次有效物理呼出/字符配对、0 次配对失败**，用户报告全部正常，正常退出码 0，受检正式文件在会话前后哈希一致。原被动观察报告保留于 [software-physical-input.json](software-physical-input.json)；实际字符仍含人工等待，不作热呼出首次可输入的 <50 ms 结论。

FemtoVG 使用首版合成夹具，实际发布目录在扫描前后均为 **1000 项**，发现到的旧 ID 由合成显示数据覆盖；正常后台发现保留。新会话有 **20 次有效物理呼出/字符配对、0 次配对失败**，用户报告全部正常；[原捕获报告](femtovg-1000-physical-input.json)和[检查点](femtovg-1000-review.json)保留 `Timeout`、回退图标和帧几何失败。后续已正常退出码 0，最终日志无丢失且配对一致，主窗口/服务窗口消失，受检正式文件与会话预检一致，见[退出补验](femtovg-1000-final-review.json)。没有强制终止该进程。

本轮未复现之前的闪现/不能输入，不能据此定位历史根因。Windows Computer Use 接口在有限重试与重新初始化后仍报告 native pipe 不存在；没有转用 shell 点击/按键绕过。实际按键与最终退出均由用户完成。
