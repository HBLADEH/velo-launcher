# RS-02 界面边界与验证重点

本项属于现有 Velo 界面的框架迁移，视觉方向已由重构计划和 Vue 最终样式确定，沿用 Windows Blue，不另做风格方案。目标是在固定 640 × 540 逻辑像素内，让用户通过搜索和六列图标识别并选择应用。

- 参照：`frontend/src/style.css` 最终层叠规则、`frontend/src/App.vue` 首页/列表，以及 `docs/images/{home-light,home-dark,search-list}.png`。历史图宽 800 物理像素、逻辑宽 640；历史首页逻辑高度 660，与本项 540 不同，不做整图像素一致声明。
- 复用：Velo 标志、Microsoft Fluent SVG、Windows 系统中文字体、蓝色强调色和深浅背景。资源嵌入二进制，不读取产品数据目录。
- 固定区域：79px 顶栏、44px 搜索框、43px 底栏；首页内容边距 22px、网格列数 6、列间距 7px、tile 高 89px；列表行高 54px。
- 内容：3 个固定项、12 个常用项、13 个系统快捷。固定组/系统组的末行不满六列；包含中英文、长中文名称、长英文路径和缺失图标。`--empty-pinned` 覆盖无固定组。
- 滚动：首页与列表分别在内容区滚动，顶栏/底栏不移动；不通过缩小字号或改列数把内容压进 540px。
- 状态：默认首项选中；鼠标经过更新选中项；点击在底栏显示已选择对象并记录固定 ID；输入即时筛选，空结果保留查询并提供清空入口。
- 外观：顶栏齿轮打开外观与关于面板，切换主题、减少动画并访问官方 AboutSlint；底栏保留主题快捷切换和退出。未实现的自定义应用、固定编辑、刷新和键盘启动按钮不显示。
- 动效：本项仅保留 140ms 列表、160ms 按钮、180ms tile/搜索边框的颜色过渡，可一键减少。滚动条为固定 6px 宽度，避免标准 Fluent 控件不可关闭的宽度/箭头过渡；入场、位移、缩放、合成输入保护及导航由 RS-03 按既有参数补齐。

验收重点为六列与不满行、末项可滚动到达、长内容省略且不覆盖其他项、主题切换保留查询、点击只记录不执行、无结果可恢复。两种 renderer 使用同一套 UI 与样例。本阶段实机证据不替代 RS-03 完整 IME/多 DPI 验证或 RS-04 资源测量。

本项无需浏览器截图工具：Slint 为原生桌面窗口，使用 computer-use 取得实际 Windows 窗口截图。样式中的 10px tile 文本、眉标、标题和分组标记沿用 Velo 基线；不按网页阅读正文规则重新设计。
