# Velo 0.10.0 Space 按键提示调整

2026-11-16，本地未发布开发快照。在[前一轮界面调整](../2026-11-16-velo-0.10.0-ui/README.md)之后，将底栏的 `Space` 改为与方向键相同的按键样式，放在回车按键右侧，共用“启动”提示。关闭空格启动时不显示 Space，Esc 的隐藏/清空提示随后排列。

本轮只修改 `rust/ui/app.slint` 的提示布局，启动逻辑没有变化。[verification.json](verification.json) 记录两种新 exe 的身份、检查回执、与前一轮相比唯一变化的源码指纹，以及 Software 截图的来源和哈希；未变化的源码指纹继续引用前一轮清单，旧结果保持原身份。

`./scripts/verify-rust.ps1 -Product -SmokeTest` 返回 0。两种渲染器各 88 项 Rust 测试、格式、Clippy、数据双向兼容、原生接口、优化构建、PE/CLI 版本及窗口/输入/业务/页面/重启冒烟通过。Software 组件示例生成 58 张合成截图，检查开启空格启动的首页、列表和网格、深浅两种主题，没有文字遮挡或间距异常。

![Space 按键提示](footer-space-keycap.png)

此图裁切自 Software debug 组件示例的合成首页截图；实际 Software 优化构建也已通过桌面截图检查。本地预览已更新并重新启动，原快捷方式、独立数据和 Ctrl+Alt+J 快捷键保留，替换前后配置、历史及应用库校验一致。该预览按用户要求保持运行，其余验证实例已退出。

本轮范围为当前 Windows 11 x64 宿主机，没有新增真实 IME、Windows 托盘鼠标点击、多屏或混合 DPI 验收，也未提交、推送或发布。正式安装和用户数据未用于测试。
