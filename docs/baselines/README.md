# 测量与验证基线

这里保存经整理的测量结果、统计和验证说明。它们用于说明测量条件和已知限制，不是跨设备性能承诺。

## 公开范围

- JSON / CSV 中保留程序身份、工具链、配置指纹、采样状态、资源数值、延迟和失败结果；用户名、个人工作区路径、机器 SID 与外部 IP 已脱敏。
- 原始应用日志、构建日志、逐事件日志和冻结采集源码副本留在本地 `.reasonix/` 归档及采集目录，不随 Git 提交。页面中的“本地原件”名称仅供维护者追溯。
- 采集字段里的原始程序 / 数据 / 工具 SHA-256 继续标识当时样本；它们不是脱敏文件的内容校验。各阶段的 `SHA256SUMS.public.txt` 校验当前公开文件，避免将两种口径混淆。
- 日常复测使用项目 `scripts/` 下的工具，步骤见[开发说明](../development.md)。正常发布程序不包含 `latencyprobe` 观察探针。
