## 保留的适用范围与限制

- 结论适用于记录中的 Windows 11 x64 环境及固定数据/会话内导入原型。Windows 10、其他驱动与第三方 IME、物理小屏的完整交互仍待后续兼容验收；通知区键盘入口未单独实测，本门槛的实际托盘入口证据为鼠标操作。不据此扩大产品发布承诺。
- 原 RS-06 保留的无前台权限后台父进程请求激活失败样本不改判。实际热键、真实托盘菜单和 Explorer 二次启动均有可输入证据；不能把任意后台进程请求激活时“可见”当成“可输入”。本门槛按已验证的用户入口判断，未发现这些入口的阻断问题。
- 前次电源请求进入离开模式；管理员读取到 `icssvc` 的 AWAYMODE 请求。本次实际 S3 在临时禁止交流离开模式后验证，测试结束已恢复原电源值。系统在原策略下再次选择离开模式属于已记录的环境边界。
- 原 RS-04 的内存预算、FemtoVG 超预算及校准延迟/长期增长待验项保留原构建身份；G2 只放行 Windows 交互阶段。正式搜索、启动、持久化、完整业务页面和产品安装包仍按 RS-08 至 RS-14 推进。

后续任务从 RS-08 的共享行为/数据用例、兼容读取与原子持久化开始；本轮没有执行数据迁移或替换正式应用。
