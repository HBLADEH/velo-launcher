# Workspace v0.3 双模式验证

2026-11-25，北京时间。测试使用独立实例、配置目录和合成应用窗口。桌面为 Windows 11 x64，构建 26340，1920 × 1080 单屏，96 DPI。

v0.12.0 Software，构建提交 `29d58206e2e8f5bc8322c7ac6dc62cb59588f960`，可执行文件 SHA-256 为 `CD574D5DC2339A5FF02E357B5663A33BDECF63995671390BD03A5FE1F6B256E6`。本机原件位于 `target/workspace-v03-baseline-software/`。

- `-Mode radial -SideButton xbutton1 -SideSamples 12 -MeasureResources`。原生侧键输入、焦点、边界与穿透断言通过。12 轮划动至可见高亮采样为 17.5–267.1 ms。记录保留 267.1 ms 的慢样本。
- 首次使用后隐藏，PrivateBytes 为 30,011,392 字节。约 3 秒空闲窗口内 CPU 增量为 0 ms。

## 双模式构建与桌面专项

基于本地工作树提交 `52ae07eaf26403248c9d09b9b0241e2a6b52dd93` 及未提交改动，锁定 Rust 1.99.1、Slint 1.18.1、MSVC 14.50.35717 和 SDK 10.0.26100.0。两种 Release 预览构建均通过 `verify-rust.ps1 -SmokeTest`，每种 146 项 Rust 测试通过、1 项忽略。

- Software SHA-256 `E03ECB9BF9201B8FC219727E0BA7C7064208E1CCC427029F0F754AF54E708561`。合成后退侧键，深色主题。原件位于 `target/workspace-v03-qa-software/`。
- FemtoVG SHA-256 `F72D842C3CD071DAD1A5707014D5735196BB585862D096AE6CB612F84B50EB7F`。合成前进侧键，浅色主题。原件位于 `target/workspace-v03-qa-femtovg/`。

桌面专项使用两个不同进程的应用窗口，验证短按命中指针下的五列专属配置，长按保持前台焦点并使用前台配置。两份构建均通过单次派发、回中心、空槽、Esc、中文与单次换行、两步快捷键、设置保存和备用键重开。两份各 10 次定点绘制采样均有画面，退出释放热键。批处理测试执行临时目录内的本地脚本，确认参数、退出码及文件改变后信任失效。迁移测试验证备份受阻时原文保留、成功后备份与旧原文逐字节相同。

独立视觉评审后削弱快捷盘中心与空槽的强调，拉开编辑按钮和应用名。独立走查验证了填充空槽和持久化，指出保存跳页与预览备用键回退。最终构建的设置截图和保存重开专项覆盖了这两处调整。

Software 补验从原生动作库确认并保存批处理信任，再划向已绑定方向。脚本在用户指定的工作目录生成了包含测试参数的回执。修改脚本后复用同一手势，执行器返回信任失效。原件位于 `target/workspace-v03-batch-smoke-3/`。

## 热态采样

两种渲染器各 12 轮，先打开工作台和启动器一次。以下各项为 P50／P95，P95 在 12 个样本中取最大值。本地结果保存每个样本。

- Software。短按释放到首个可见帧 12.7／70.2 ms，划动到可见高亮 50.6／68.1 ms，划动到 Rust 选择记录 6.7／26.4 ms，松开到启动器派发日志 27.5／39.8 ms。
- FemtoVG。短按释放到首个可见帧 13.2／18.7 ms，划动到可见高亮 50.0／51.6 ms，划动到 Rust 选择记录 2.1／32.6 ms，松开到启动器派发日志 28.2／70.1 ms。
- 约 3 秒用后隐藏的最终空闲采样中，Software PrivateBytes 为 30.41 MiB，FemtoVG 为 88.69 MiB，两者 CPU 累计增量均为 0 ms。

Software 短按 P95 高于策划建议的 50 ms，两种渲染器的选择日志 P95 均高于建议的 2 ms。新版高亮采样从快速划动开始，包含快捷盘展开和窗口重绘。旧版采样从中心已可见后划动开始，两组数据的可见阶段不同。启动器派发记录包含启动器界面交接，动作队列入口延迟另待采样。
