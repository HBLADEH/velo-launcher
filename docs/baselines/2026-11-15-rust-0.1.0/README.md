# Rust 0.1.0 正式发行验证

2026-11-15。所有者授权以精确标签 **0.1.0** 发布 Rust + Slint 首个正式版本，后续产品开发切换到 Rust，Go/Wails 0.9.x 停止维护。源码、许可、最终安装包和测试结果见 [发行验证清单](release-validation.json)。

两种产品构建各 223 项输入、87 项 Rust 测试、clippy/格式、Go/Rust 双向数据、原生功能、PE 资源与窗口/输入/业务/页面/重启冒烟通过。源码来自干净提交，所有输入同时核对工作文件、Git 原始对象及包内 SHA256。正式元数据为 0.1.0，默认 Software，FemtoVG 使用独立更新资产；新增 API 与限流订阅回归确认忽略数值更大的旧 Go 版本，并保持 renderer。

在现有隔离 Windows 10 客户机运行最终安装器的 Prepare / Switch / Rollback / Cleanup，9 项断言通过（含新增并发安装拒绝）：锁定和未知 Go 拒绝、Go 原位接管、锁定 Rust 拒绝、替换后故障恢复、Software→FemtoVG 升级、Go 精确回退、Rust 卸载保留未知文件和档案。另补齐正式包全新安装、正式注册名称/版本、无 Go 快照时回退拒绝、全新卸载；旧测试和本次恢复档案均保留。最终无程序、安装注册或快捷方式遗留，合成数据原文不变。

客户机停在登录界面时，通过已认证的 VMware Tools 后台接口执行安装器测试，没有自动处理登录或 UAC。当前界面冒烟在宿主机隔离身份完成；当前 exe 未重复真实 IME、性能或所有 DPI。此前 [G4 / 搜狗验收](../2026-11-07-slint-rs14/machine-completion-2026-11-14/g4-acceptance.md) 保留原 exe 身份，范围仍为现有 Windows 11 / Intel UHD 630 宿主机及 Windows 10 VMware 客户机，不可用实体环境继续跳过。

两个安装器各自包含完整许可；公共许可 ZIP 分别保存 Software 和 FemtoVG 清单与文本，缺失文本为 0，Slint 选择 Royalty-free 2.0，并保留 AboutSlint。发行资产只有系统安装器、许可 ZIP、构建清单与 SHA256，没有独立免安装版。

首次检查因整理换行误改二进制图标而在资源编译前失败；已恢复 ICO/PNG 原字节，保留本地失败日志，本清单只绑定完整重跑成功的构建。宿主机正式数据五项指纹与原参考一致，未用于测试。

虚拟机曾因客户机自动睡眠挂起，恢复时误启的并发恢复与原协调器重叠，导致一次新装失败；现已在安装/卸载/回退入口增加全局互斥，新增真实跨进程拒绝用例通过，原失败未删除。先前两轮 CI 分别因原生探针被本机防护拦截而取消/失败；后将扫描驱动与最小参数回执程序分离，保留实际原生能力及更新覆盖，无防护设置修改。

新默认 GitHub CI 验证 Rust 正式身份并打包，Go/Wails 工作流仅保留手动历史复现入口。[本次实际 CI](https://github.com/HBLADEH/velo-launcher/actions/runs/43632029992) 成功，精确绑定最终源码；不能用旧 RS-14 CI 结果替代本次运行。公开安装器来自本机已实际测试的文件，CI 自身产物具有独立构建身份，不混用哈希。
