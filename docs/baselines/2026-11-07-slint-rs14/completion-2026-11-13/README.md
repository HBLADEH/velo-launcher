# RS-14 默认渲染器、许可与实际安装续验

2026-11-13（北京时间）。**已选择 Software 为本机 Windows 11 x64 的默认渲染器，FemtoVG 保留为显式替代构建；本机可执行的安装/更新验证已补齐。RS-14/G4 仍待远端 CI、其他兼容环境和正式全系统安装迁移证据。** 本轮保留所有失败和原构建身份，没有替换正式应用、提交、推送或发布。

## 渲染器与构建

[决策](renderer-decision.md)综合原 RS-12 同机性能矩阵、RS-13 当前程序的真实输入/视觉签收及[新资源补验](resources-summary.json)。两条路径各三种空闲状态、各 3 个 15 秒有效样本，另有各 100 次显隐后的两组可见复采，共 **30 份有效样本**。Software 可见/隐藏五分钟 PrivateBytes 中位数约 **19.91/19.98 MiB**，FemtoVG 约 **53.41/50.79 MiB**。当前有探针、实际发布 622 项且有扫描警告，不能与旧普通模式相减归因；不重复计作冷启动或 30 分钟循环。

原两组失焦可见样本仍为无效，补采没有覆盖或删除它们。Software 动画变化帧间隔较长、非零可见 CPU、GPU 不可采字段及历史失焦根因缺证保持原状；默认选择没有抬高预算。Windows 10、其他驱动/IME 和本机不可选的 200% 没有宣称通过。

资源与物理验收继续绑定本轮开始时的两个 **206 输入** exe。本轮完整验证重新链接后产生新文件哈希；[逐字节比较](build-equivalence.json)仅归一化 PE 明确定义的 COFF/调试目录时间戳和 CodeView RSDS GUID，确认除此之外全文件一致。没有忽略代码/资源区差异，也没有把旧物理输入记录重标成新文件。[构建与回执](build-identities.json)保存各次程序和来源对应关系。

## 许可与打包

[技术审查](license-review.md)完成锁定表达式的明确选项、AND 条件保留、Slint Royalty-free 2.0 与实际 AboutSlint、三个嵌套文本和 **11 份 Khronos 内嵌声明**。ANGLE BSD 原文追溯精确 git submodule，当前补充共 **42 份**文本。两包缺文本为 **0**，根文本缺失与补充收集仍分开计数；未知表达式会被拒绝。原生/optional 范围依据实际 active Cargo tree，不把 Skia optional metadata 当成最终链接的 vendor。

两 renderer 的 ZIP 各拒绝五类无效输入，逐文件 SHA 校验通过，并验证嵌套/内嵌声明与库存一致。Software/FemtoVG 当前首轮为 **601/605** 个文件。包元数据的默认 renderer 来自 `rust/windows/release-policy.json`，G4 和内部发行标志独立保存，不因默认选择自动发布。

## 实际安装、回退与 UAC

两份固定隔离 NSIS 各 **8 项**检查通过，增加卸载前拒绝锁定程序，保留错误目标、中文空格路径、安装后窗口、升级、精确旧字节恢复和未知文件/五份合成数据保留。编译使用 `/WX`；修复了此前候选的卸载命令引号警告，并明确 64 位 HKCU 注册视图。

两个不禁用注册的实际每用户候选各 **6 项**场景通过：真实 HKCU/开始菜单入口、隔离参数、实际窗口、锁定安装/卸载保持注册、升级及卸载清理。程序目录通过 `/D` 留在任务目录；开始菜单和卸载项真实创建后删除，默认预览数据未打开。此前“只编译候选”的结论不再当成当前状态。

当前两条 **Go portable ZIP → 实际 NSIS Rust → 保留 Go** 回退链路通过；三阶段读到同一份 1000 项合成目录，配置、历史、应用库和原始备份字节不变。写入兼容仍由 Go/Rust 双向数据契约支撑；这不代替正式 Go 管理员安装器的系统注册迁移。

用户配合完成 **Software/FemtoVG × 确认/取消，共四组真实 UAC**。测试先备份配置并限制任务目录的写权限，确认普通令牌不能写入，再运行生产 `core::update::script` 和实际固定 NSIS。选择“是”后新字节替换、包/脚本清理与后台重启通过；选择“否”后旧 exe 精确字节、包/脚本和错误日志保留，日志含取消原因，旧程序后台重启。四份配置与原始备份未变，均由用户从托盘退出，目录访问规则/继承保护/所有者/组恢复。[用户操作](operator-reports.json)与[四组结果](uac-results.json)分开保存，未修改安全策略或使用无提示提权冒充同意/取消。

## 验证与失败保留

`verify-rust.ps1 -SmokeTest` 覆盖两条路径各 **80 项 Rust 测试**、22/7/33 项输入/业务/页面断言、clippy/格式、数据往返/NTFS 失败保持、Windows/启动、PE 元数据和 Release。旧版 Go 1.25.6 的 `verify.ps1 -SkipBuild` 也通过。权限比较的验证脚本修正另纳入最终全量回执；该修正只比较权限语义，没有修改产品或降低 ACL 恢复要求。[检查记录](verification.json)绑定日志和脚本 SHA。

三个实际失败保持可查：首轮 FemtoVG 安装后窗口有非空快照，但 `redraw_events=0` 导致 smoke 失败，原任务安装器正常卸载后在新目录串行复验通过；当时旧版回归并行运行是观察条件，不证明根因。第一次 UAC 结束的 ACL 检查因原始 SDDL 字符串不同拒绝，逐项复核实际 8 条访问规则、继承保护、所有者/组相同；修正脚本比较这些语义属性后通过，原错误记录保留。最终双路径入口的 Software 业务冒烟在前 3 项通过后失焦、按正常显隐隐藏并超时；使用相同源码的官方 Software 单路径完整入口重跑，原失败和未明确的前台变化原因保留。没有修改 UI/产品参数或测试阈值来使检查通过。
