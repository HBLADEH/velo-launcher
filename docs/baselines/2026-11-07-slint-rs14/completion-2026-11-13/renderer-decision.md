# 默认渲染器决定

2026-11-13（北京时间）。**Software 为已测 Windows 11 x64 范围的默认渲染器，FemtoVG 保留为显式替代构建。** 这是 RS-14 的工程选择，不代表远端 CI、其他 Windows/驱动环境或 G4 已通过。

选择依据包括 [RS-12 综合测量](../../2026-11-04-slint-rs12/completion-2026-11-11/README.md)、[RS-13 当前程序实机验收](../../2026-11-07-slint-rs13/completion-2026-11-13/README.md)及本轮[当前资源补验](resources-summary.json)。两条路径均已具备本机输入、中文合成、焦点、页面和视觉证据；用户已接受具体的字形、阴影和原生菜单差异，没有以减少功能取得内存结果。

## 内存与 CPU

原 RS-12 普通业务模式的可见/隐藏五分钟 PrivateBytes 中位数为 Software **26.32/26.12 MiB**、FemtoVG **55.03/67.30 MiB**。这些数字保留原 exe 身份和采样范围。

本轮没有重建被测产品，复用 RS-13 真实输入验收的 Software `5E7C017DDA3FF691E7FF8DCBFEAF149E5A766C1F8DC73A816BB5C4A9F7C4C66B` 与 FemtoVG `D81F31ED8AB3C0D45A3565CDC8AA412B3FB870C0CC350204178CDE44456B6487`。相同原始业务 seed、顺序运行、真实发现与图标预热后的可见私有提交中位数约 **19.91/53.41 MiB**，Software 隐藏五分钟约 **19.98 MiB**。本轮有测量日志/管道，实际目录状态与旧轮不同，故不计算跨轮“优化收益”或探针成本。

全部三态、私有工作集、工作集、CPU、线程/句柄、图标估算、100 次显隐后复采及原件 SHA 见资源汇总。两份程序均正常退出，原两组失焦导致的无效可见样本保留；扫描有警告但确有发布新快照，不能称为无警告全量发现。`Minutes=0` 明确没有重复 30 分钟循环。可见 CPU 的非零值和 GPU 指标不可采状态也保留，PrivateBytes 不用来冒充物理常驻。

Software 在当前及原冻结同机范围都满足可见 ≤50 MiB、隐藏争取 ≤30 MiB 的私有提交预算；FemtoVG 可见超出 50 MiB，仍不调整预算。原动画采样中 Software 的变化帧间隔 P95 约 66.7/67.0 ms，FemtoVG 更平滑，但对应查询窗口的整树 CPU 成本更高；这项帧节奏取舍必须保留。它不是 GPU 执行时间，也不能推断高 DPI 下所有动画的 CPU 分布。

## 延迟、兼容与剩余风险

原冻结程序各三次独立冷接收上界 P95 为 Software **287.492 ms**、FemtoVG **473.743 ms**；各二十次机器热键校准上界 P95 为 **44.818/26.741 ms**，两者分别在 500/50 ms 参考目标内。物理热键/IME 与机器计时分列，未将这些冻结时序改标为本轮重测。Software 的内存、冷启动及较低驱动依赖更符合当前轻量化方向，FemtoVG 的热键/动画节奏优势不足以抵消已测常驻成本。

RS-13 已在上述当前 exe 上完成真实微软拼音、100/125/150/175% 与跨屏验收，有限原生设置过渡也有合格样本；不声称所有帧或唯一曲线严格相同。200% 在本机不可选，Windows 10、其他 GPU 驱动及第三方 IME 未实测。历史首次显示失焦的原始原因仍缺证，后续回归通过不等于历史故障已被证明修复。

## 构建与替代方法

[release-policy.json](../../../../rust/windows/release-policy.json)是打包默认选择的来源，包元数据同步保存选择及适用范围。Cargo 不启用隐式 renderer：继续用 `verify-rust.ps1 -SmokeTest` 串行检查两条路径，每份构建恰好启用一个 renderer feature。

需要比较或替代时，正常退出当前预览，从另一条 renderer 的 ZIP/内部安装器启动；两种预览使用同一 preview 身份/数据，不能同时运行。renderer 是构建选择，不通过环境变量在同一 exe 上静默回退。正式数据、旧 Go/Wails 程序及正式安装包继续保留。
