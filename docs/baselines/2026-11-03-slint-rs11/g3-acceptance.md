继续保留 Go 对照版本，不替换正式安装包，不将当前验证版或原型目录改标为正式 Velo。RS-12 的完整资源矩阵仍以 G3 放行为前置；本轮不选择默认渲染器，也不扩大 Windows 10、第三方 IME 或驱动兼容结论。

补验只使用独立实例和数据副本：

1. 从普通权限实例的真实右键菜单发起管理员 helper，分别确认和取消 UAC；检查参数/工作目录、成功历史、取消无历史和后续输入。
2. 从系统快捷打开锁屏/回收站/电源确认的适用路径；电源项只取消，检查提示所有权和输入恢复。实际清理/电源行为需另有明确测试条件。
3. 在固定位置的独立原型启用登录启动，完成一次真实登录会话，检查隔离参数、后台状态和呼出输入；关闭后核实命名值移除。
4. 有 Rust 安装资产后，在隔离安装目录验证不可写目标的安装器分支、UAC 取消、失败恢复、自动备份和重启，以及旧数据读回。
