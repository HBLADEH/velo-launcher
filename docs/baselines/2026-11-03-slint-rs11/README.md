# RS-11 完整页面与系统集成

日期：2026-11-03（北京时间）。路线：[Rust + Slint 重构计划](../../rust-slint-refactor-plan.md)。本轮继续使用独立原型标识与数据目录，不替换 Go 程序或正式安装包。

## 交付

- 正常模式补齐常规、快捷键、外观、搜索、索引、备份、关于七个设置页，支持搜索列表/六列网格与四方向键、设置草稿的显隐保留、系统主题和减少动画。
- 结果和首页支持所属原生右键菜单：打开、安装目录、管理员打开、固定/取消固定。不支持的目录/管理员动作禁用，菜单取消回到实际前台归属。
- 自定义应用通过拖放、文件选择或路径检查后显式导入；解析 `.lnk` 参数/工作目录，保留 ID，去重，不执行或自动固定。每批 100 个、应用库 1000 个、固定 200 个；删除应用与固定项同文件原子提交，刷新接受最新库，不恢复已删自定义项。
- 设置预注册新热键时保留旧注册；登录项和配置提交失败释放预注册、恢复登录项原类型/原字节，旧配置和快照继续可读。成功后在提交锁内取消旧配置扫描，再后台刷新，避免旧结果穿过提交边界。登录项使用 `VeloSlint-<instance>` 与明确隔离参数，保留正式 `Velo` 值。
- 备份沿用磁盘原文，更新前备份失败阻止生成/执行脚本。更新使用 WinHTTP、版本比较、GitHub API 限流后的公开页面回退、受控临时下载、SHA-256 校验、进度与取消。脚本再次校验、等待旧进程退出，支持便携替换或安装器提权，携带原型隔离参数重启。
- 系统工具定义取自现有 Go 目录，按 Windows build、协议注册、文件和用户/机器策略筛选。内置协议/电源动作要求完整身份匹配；关机/重启默认取消，回收站保留 Windows 确认，取消不学习历史。

实现边界：`ui/settings.slint` 负责设置控件与草稿；`business.rs` 适配显示/回调；`core/library.rs`、`system_tools.rs`、`update.rs` 管理规则；磁盘和 Shell 命令使用有界后台线程；Windows 注册表、网络、弹窗、动作与更新进程均集中在 `platform/windows/`。没有引入常驻 Go、WebView 或 HTTP 服务。

标准入口：`./scripts/verify-rust.ps1 -SmokeTest`。旧版回归：Go 1.25.6 下 `./scripts/verify.ps1 -SkipBuild`。

## 保留的失败记录与差异

- 初次页面脚本在保存前与自动更新检查重叠，未完成该轮；受控 fixture 已关闭自动网络检查，真实更新检查单独验证，不把未完成轮次记为通过。
- 截图复查发现标题栏/导入按钮缺少明确坐标时被 Slint 默认居中，已分别固定布局；最终截图和身份重新采集。
- 原生脚本首轮因继承 PowerShell 7 的模块路径而无法在 Windows PowerShell 识别 `Get-FileHash`；已改为 .NET SHA-256 并清除子进程的模块路径覆盖，临时目录替换/恢复复验。
- 原型只接受 `velo-slint.exe` / `velo-slint-x64-installer.exe` 和 `SHA256SUMS.txt`，现有 Go 发布包不会覆盖 Rust 原型。发布资产命名及正式安装包切换按 RS-14 决定。
- 一次额外旧数据副本脚本在外层文件重定向下触发 PowerShell 的 `StandardOutputEncoding is only supported when standard output is redirected` 启动错误，未开始该轮检查；保留本地 `rs11-old-copy-final-femtovg.failure.log`，改用 transcript 记录后以同一脚本、同一 exe 和新副本复验通过。
- 取消系统确认不再作为成功学习历史；这是明确的失败/取消语义，保持动作取消后用户数据不变。

## G3 结论

RS-11 功能已接通，自动与数据副本验收范围见上表；[G3 结论](g3-acceptance.md)为**不放行**。真实 UAC 桌面、登录后实际自动启动、已发布 Rust 安装器升级仍需实机证据；当前不把这些项目写成通过，不推进 RS-12 或选择默认渲染器。
