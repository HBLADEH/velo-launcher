# Workspace v0.3 双模式工作台

## 设计

- Windows 桌面用户在指针附近点击常用动作，或按住侧键快速操作前台应用。常用尺寸为 300 × 348 DIP 的短按工作台和 278 × 218 DIP 的快捷盘。
- 短按优先呈现两组动作。控制带显示 Velo 标志、指针下的应用以及两组编辑入口。按住时中心只显示状态，划动后显示八方向卡片。
- 每组默认 3 列 2 行，可分别调整为 4 或 5 列。空位留在原序号，设置里可以点击或拖入动作。编辑、交换和保存也可通过键盘完成。
- 浮窗使用紧凑圆角底板与独立卡片。字体、深浅表面、蓝色焦点反馈、Logo 和通用图标沿用现有 Windows 蓝主题。
- 矩阵可见后立即接受点击。快捷盘的方向和松手提示直接跟随 Rust 判断。持键静止或回到中心时显示「松开取消」，有效方向显示「松开执行」。
- 通用、短按工作台、长按快捷盘和动作库通过设置内的四个页面访问。选择应用时可使用当前捕获的应用、完整路径、包标识或系统文件选择器。

## 实施顺序

1. **P0 测量与方向算法**。先在本机执行 v0.2 原生专项。新方向算法使用 180 ms 长按阈值、20 DIP 划动起点、14 DIP 取消半径及 8° 滞回。工作区夹紧只改变浮窗位置。运行时按真实按下点换算方向。
2. **P1 双模式和独立配置**。短按使用指针下应用，应用动作也以该窗口为目标。手势和全局输入动作使用触发时的前台应用。解析器在有界缓存中按窗口身份查询结果，超过可用时间采用默认组。快捷盘采用非激活显示，监听线程在活动手势中处理 Esc。
3. **P2 动作库**。实现 Unicode 文本、按行排列的快捷键步骤、本地批处理和打开目标。步骤间核对前台窗口、进程创建时间及输入焦点。批处理由系统 `cmd.exe` 在独立作业中运行，验证文件及执行参数的指纹，超时或取消时结束作业内的进程。服从程序当前权限。
4. **P3 兼容与验收**。新构建的工作台入口统一使用短按矩阵和八方向快捷盘。启动时直接读取已保存的矩阵和手势。仅有旧版槽位时，按旧顺序迁入全局、默认和应用矩阵，方向从空白开始。首次保存前备份旧配置原文，再原子写入新布局。关闭工作台后释放侧键、热键、浮窗和上下文查询线程。

应用显式空手势组优先于默认手势组。发布前的 Windows 版本、实体鼠标、显示器和资源验收按各构建实测记录。 [Workspace v0.3 验收](../../baselines/2026-11-25-workspace-v03/README.md)
