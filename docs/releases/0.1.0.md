# Velo 0.1.0 — Rust 首个正式版本

Velo 已重构为 **Rust + Slint 原生单进程应用**，不再依赖 Go/Wails、WebView2 或本地 HTTP 服务。版本号从 **0.1.0** 重新起算；后续功能与修复以 Rust 为主线，Go/Wails 0.9.x 停止维护。

## 下载与安装

- `velo-rust-x64-installer.exe`：Windows 10/11 x64 系统安装版，默认 Software 渲染器。
- `velo-rust-femtovg-x64-installer.exe`：FemtoVG / OpenGL 替代构建，切换前请从托盘完全退出 Velo。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。
- `velo-rust-0.1.0-licenses.zip`：项目及第三方许可、依赖清单。
- `release-manifest.json`：源码、工具链、渲染器和安装器构建身份。

本次提供系统安装版。请手动运行安装器并确认 UAC；没有独立免安装版。安装包未做 Authenticode 签名，Windows 可能显示未知发布者。

## 从 Go 版本迁移

先从托盘退出旧 Velo。已核对的官方 **v0.9.11 系统安装**支持原目录接管；其他旧构建请先卸载并保留数据，再安装 Rust。因版本号重新起算，请手动下载本次安装器，旧 Go 更新器不会自动升级到 0.1.0。

继续使用 `%LOCALAPPDATA%\Velo` 中的设置、历史、自定义应用和固定项。首次打开数据前，Rust 将原始文件完整备份到 `%LOCALAPPDATA%\VeloRustMigrationBackups`；备份失败时停止初始化。安装器保留原程序恢复档案，失败会恢复旧状态，卸载保留用户数据和未知文件。

## 功能与后续更新

安装与卸载使用系统范围的互斥锁。另一个安装或卸载进行中时会提示等待，并在修改程序、注册或恢复记录前拒绝重叠操作。

保留中文/拼音/首字母搜索、历史排序、自动索引、固定与常用应用、系统快捷、自定义应用、列表/网格、主题、热键、托盘和配置备份。IME 合成期间优先处理候选输入。

Rust 更新会验证 SHA-256 并在安装前备份配置，仅选择对应 Rust 渲染器资产，忽略数值更大的旧 Go 版本。Software 与 FemtoVG 分别更新。

## 验证范围

RS-14 / G4 在当前 Windows 11 x64 / Intel UHD 630 宿主机及隔离 Windows 10 x64 客户机范围通过，覆盖正式身份、原位接管、故障恢复、升级、回退、卸载和真实搜狗输入。不可用实体硬件按本轮范围跳过。

既有性能测量保留各自构建身份：Software 动画帧节奏、FemtoVG 内存及大规模慢查询仍有取舍，不承诺所有设备达到统一内存预算。完整依据见仓库中的重构计划和验收记录。
