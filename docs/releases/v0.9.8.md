# Velo v0.9.8

本次预览版修复启动应用后再次呼出仍保留上次搜索内容，以及部分呼出场景下搜索框未获得焦点的问题。

## 更新内容

- **启动后清空搜索**：普通启动和管理员启动成功后清空输入、搜索结果及选中位置，再次呼出从首页开始。启动失败时保留输入与选中项，便于重试；只隐藏窗口时仍保留当前页面和搜索内容。
- **恢复窗口与搜索焦点**：呼出窗口时同步激活 Wails WebView，修复原生窗口已经显示、网页输入框仍未获得焦点的情况；保存设置后也沿用搜索焦点恢复逻辑。
- **等待焦点就绪**：当窗口显示事件先于 WebView 获得焦点时，每隔 50 毫秒重试，最多尝试 20 次。窗口隐藏、失焦或页面卸载时取消等待；设置、自定义应用和右键菜单打开时不抢占搜索焦点。
- **重复启动状态同步**：已有 Velo 进程时，再次运行程序并激活原窗口，即使没有收到窗口显示事件，也会同步前端可见状态并恢复搜索框焦点。

## 下载与安装

支持 Windows 10 / 11 x64，需要 Microsoft Edge WebView2 Runtime。

- `velo-launcher.exe`：免安装版，完全退出 Velo 后替换原程序。
- `velo-launcher-amd64-installer.exe`：安装包。
- `SHA256SUMS.txt`：发布文件的 SHA-256 校验值。

设置与缓存仍保存在 `%LOCALAPPDATA%\Velo`，配置备份在其 `backups` 子目录中。可在“设置 → 关于”中检查更新。

## 验证与限制

新增 13 项前端回归测试，直接测试启动器组件逻辑，覆盖普通与管理员启动成功后清空、失败后保留、窗口显示先于原生焦点、仅收到原生焦点事件时的可见状态同步、设置与菜单焦点保护，以及重试的取消与上限。

本地前端 lint、类型检查、20 项前端测试、Go vet 和全部 Go 测试通过。本次修复尚未在真实桌面上完成手动复测，实际快捷键、托盘呼出、管理员启动与重复启动的完整交互仍需实机回归。

窗口位置和隐藏的页面状态仅在当前运行期间保留，完全退出后从首页开始。软件界面为简体中文，发布文件暂未签名，完整性能与长期稳定性验证仍在进行。
