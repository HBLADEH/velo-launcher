# Velo v0.9.4

本次预览版完善设置界面的主题与交互，新增快捷键录制，并整理项目文档。

## 更新内容

- 主题选择改为自定义菜单：支持浅色、深色、跟随系统，以及方向键、Enter、Esc 操作；空间不足时向上展开。
- 统一复选框、输入框和菜单的悬浮、焦点、选中与过渡效果，遵循系统减少动画偏好。
- 全局快捷键支持点击录制：按下组合键即可记录，点击“保存设置”后生效；支持取消、失焦退出和无效组合提示。
- 录制当前已绑定的快捷键时保持窗口显示，不会意外隐藏启动器；取消录制不改变原有绑定。
- 增加按键解析和录制窗口行为的回归测试，前端测试纳入统一验证脚本。
- 中文 README 加入真实界面截图，新增英文 README、用户指南、双语贡献指南和截图维护说明。

## 下载与安装

支持 Windows 10 / 11 x64，需要 Microsoft Edge WebView2 Runtime。

- `velo-launcher.exe`：免安装版，退出 Velo 后替换原程序。
- `velo-launcher-amd64-installer.exe`：安装包。
- `SHA256SUMS.txt`：发布文件的 SHA-256 校验值。

两种发行方式均使用 `%LOCALAPPDATA%\Velo` 保存设置与缓存。v0.9.3 用户可在“设置 → 关于”中检查更新；更早版本建议手动下载安装。

## 验证与限制

本地验证覆盖格式检查、前端 lint / 类型检查 / 按键解析测试 / 构建、go vet 和 Go 测试。实机已验证浅色与深色主题菜单、键盘选择、取消录制、Ctrl+Shift+F8 和当前绑定的 Alt+Space；辅助输入方式缺少物理键码时的字母兼容分支已通过自动化测试，尚未完成最终实机复测。

软件界面仍为简体中文。系统保留的快捷键可能无法录制或注册；被其他程序占用的快捷键会在保存时提示。发布文件暂未签名，完整性能与长期稳定性验证仍在进行。
