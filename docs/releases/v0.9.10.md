# Velo v0.9.10

本次预览版简化主界面，并将网格搜索中的应用与系统快捷合并展示。

## 更新内容

- **简化主界面**：移除主菜单右下角的“退出”按钮，可通过通知区域托盘图标的右键菜单退出 Velo。
- **统一网格搜索结果**：原“搜索结果”为普通应用，“匹配结果”为系统快捷，仅按来源分组。现在合并为一个连续网格，与列表模式一致，统一按搜索排名排列。
- **同步导航与布局**：四个方向键可在合并后的网格中连续选择，切换列表与网格保持选中项一致；窗口高度按实际网格行数调整，并同步更新设置说明与用户指南。

## 下载与安装

支持 Windows 10 / 11 x64，需要 Microsoft Edge WebView2 Runtime。

- `velo-launcher.exe`：免安装版，完全退出 Velo 后替换原程序。
- `velo-launcher-amd64-installer.exe`：安装包。
- `SHA256SUMS.txt`：发布文件的 SHA-256 校验值。

设置与缓存仍保存在 `%LOCALAPPDATA%\Velo`，配置备份在其 `backups` 子目录中。可在“设置 → 关于”中检查更新。

## 验证

本地 `verify.ps1 -SkipBuild` 通过，包括前端 lint、类型检查、25 项前端测试、生产构建、Wails 绑定生成、Go vet 与全部 Go 测试。

回归测试覆盖混合来源的搜索排名、网格跨行导航、布局切换后的选中项保留，以及启动目标与选中项一致性。

软件界面为简体中文，发布文件暂未签名，完整性能与长期稳定性验证仍在进行。
