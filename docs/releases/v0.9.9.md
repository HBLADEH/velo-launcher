# Velo v0.9.9

本次预览版修复空回收站仍报告 `0x8000FFFF` 的问题，并将搜索清空时机提前到启动指令发出后。

## 更新内容

- **空回收站信息提示**：清空前检测回收站；已为空时显示“回收站已为空，无需清理。”，仅有“确定”按钮，按空格或 Enter 即可关闭。有内容时保留 Windows 自带的清空确认提示。
- **修复回收站检测**：查询结构与程序的 32/64 位架构保持一致，避免 64 位程序因结构大小错误而无法判断回收站为空。清空接口返回 `0x8000FFFF` 时再次确认当前状态，回收站已空则正常结束；实际操作失败仍显示错误。
- **立即清空搜索**：普通和管理员启动指令发出后，立即清空输入、搜索结果和选中位置，无需等待应用启动或系统确认框关闭。启动失败仍提示错误，不恢复旧查询；启动调用后续返回也不会清空等待期间新输入的内容。

## 下载与安装

支持 Windows 10 / 11 x64，需要 Microsoft Edge WebView2 Runtime。

- `velo-launcher.exe`：免安装版，完全退出 Velo 后替换原程序。
- `velo-launcher-amd64-installer.exe`：安装包。
- `SHA256SUMS.txt`：发布文件的 SHA-256 校验值。

设置与缓存仍保存在 `%LOCALAPPDATA%\Velo`，配置备份在其 `backups` 子目录中。可在“设置 → 关于”中检查更新。

## 验证

本地前端 lint、类型检查、24 项前端测试、Go vet 和全部 Go 测试通过。回归测试覆盖普通与管理员启动的立即清空、失败提示和新查询保留，以及空回收站、零字节文件、取消操作、查询失败和实际清空失败。

32/64 位 Go 原生回收站查询均已只读验证；空回收站信息提示使用真实 Windows 消息框显示，并实测按空格关闭后正常返回。实际提示截图见 [空回收站信息提示](https://github.com/HBLADEH/velo-launcher/blob/v0.9.9/docs/images/empty-recycle-bin-notice.jpg)。
