# Velo v0.9.3

本次预览版修复自动更新下载完成后未执行安装脚本的问题。

## 更新内容

- 修正后台 PowerShell 的进程创建参数，避免进程创建成功却未执行更新脚本；脚本可在 Velo 退出后继续运行。
- 安装版更新先等待旧进程退出，再安装到原目录，避免文件占用及自定义安装目录丢失。
- 安装失败或取消 UAC 时保留安装包与脚本，尝试重新打开 Velo，并将错误写入 `updates/velo-update-<PID>.ps1.log`。

## 下载与验证

Windows x64，需要 Microsoft Edge WebView2 Runtime。提供 `velo-launcher.exe` 独立程序、`velo-launcher-amd64-installer.exe` 安装包和 `SHA256SUMS.txt` 校验文件。

**旧版本的自动更新程序仍有此问题，请手动下载并退出 Velo 后安装本版；便携版请退出后替换原 exe。**

已通过后台脚本执行、父进程退出后继续运行，以及模拟安装成功、失败和取消 UAC 的回归测试。完整的实机安装升级测试留待后续，发布文件暂未签名。
