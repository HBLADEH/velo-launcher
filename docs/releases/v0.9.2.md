# Velo v0.9.2

本次预览版改进桌面应用发现、常用排序，并扩充按本机能力筛选的 Windows 系统快捷入口。

## 更新内容

- 修正桌面快捷方式索引：扫描 Windows 实际的用户桌面（包含 OneDrive 重定向）和公共桌面；纳入目标文件存在的 `.lnk`，排除空目标、损坏或失效的桌面链接，继续跳过 `.url` 网络及协议快捷方式。
- 同一应用同时存在桌面、开始菜单和程序文件入口时，优先保留桌面名称和快捷方式；合并其他名称作为搜索别名，启动仍保留快捷方式参数与工作目录。刷新时重新检查目标是否存在。
- 支持中文应用名称及别名的拼音、首字母检索，例如 `ld`、`leidian`；搜索结果优先显示实际目标程序路径。
- 首页常用应用优先按启动频次与最近使用时间排序，预设应用只补充剩余位置。历史记录在重启后保留，且不再被搜索历史权重设置关闭。仅统计通过 Velo 启动的记录。
- 系统快捷扩展至 40 个入口定义，按系统版本、已安装组件、设置协议和设置页可见性策略筛选；支持系统配置、信息、颜色、激活、恢复、更新，以及计算机管理、磁盘清理、事件查看器等。
- 首页系统快捷默认展示 12 项，可展开全部、固定，并按使用记录排序；暂时不可用的固定系统入口隐藏，恢复可用后重新出现。选择入口仅打开对应 Windows 页面或工具。
- 补充拼音依赖的开源许可和索引、排序、系统能力检测的回归测试。

## 下载与验证

Windows x64，需要 Microsoft Edge WebView2 Runtime。提供 `velo-launcher.exe` 独立程序、`velo-launcher-amd64-installer.exe` 安装包和 `SHA256SUMS.txt` 校验文件。

发布产物来自版本标签对应的 Windows CI。校验方法：

```powershell
Get-FileHash .\velo-launcher.exe -Algorithm SHA256
```

桌面索引已使用本机真实 `.lnk` 与 Steam `.url` 验证；系统入口完成只读发现、版本/策略/组件筛选测试。企业策略、不同 Windows SKU 及安装后的完整自动更新流程仍需实机回归。发布文件暂未签名。
