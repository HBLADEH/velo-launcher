# Velo v0.9.11

本次预览版修复首次启动后搜索框需要点击才能输入的问题，并补齐资源、启动延迟测量工具及轻量化评估文档。

## 更新内容

- **修复首次启动焦点交接**：首次显示等待原生窗口和前端就绪；当焦点已停在顶层宿主时，产生真实焦点转换，让 Wails 将焦点交给 WebView 搜索框。
- **保留后台启动与显隐行为**：快捷键注册成功时后台启动保持隐藏；快捷键不可用时显示窗口；迟到或重复的前端握手不会重新打开已隐藏的窗口。
- **补齐回归测试**：新增真实 Win32 焦点转换、原生 / 前端两种就绪顺序、显隐优先级和初始隐藏时缓存首页加载的测试。

## 开发与验证工具

- 加强完整进程树资源采集：程序 / 数据指纹、CPU 采样有效性、窗口显隐持续观察、空闲依据及稳定性判定。
- 新增 `Service.Home` / `Service.Search` 基准，覆盖 100 / 1000 / 5000 应用以及有无历史记录的场景。
- 增加仅测试构建启用的输入就绪探针、GUI 启动与真实快捷键采集、冷条件预检、启动项备份恢复和中位数 / P95 汇总；对应工具回归纳入统一验证脚本。
- 整理[测量基线](https://github.com/HBLADEH/velo-launcher/blob/v0.9.11/docs/baselines/README.md)、[轻量化执行计划](https://github.com/HBLADEH/velo-launcher/blob/v0.9.11/docs/lightweight-optimization-plan.md)与[架构评估](https://github.com/HBLADEH/velo-launcher/blob/v0.9.11/docs/architecture-review.md)。公开证据已脱敏，原始本机日志与用户数据不入库。

## 当前边界

- 技术栈仍为 Go + Wails + Vue；本版未集成 Everything，也未增加组合启动或迁移 UI 框架。
- 已有资源基线中 WebView2 是私有提交的主要来源，本版不宣称已降低内存或达成全部性能目标。
- 焦点修复已有一次全新 WebView 配置、正常生产模式的自动聚焦观察；额外的跨应用快捷键实机验证受自动化工具安全检查限制，完整新版冷 / 暖启动和热呼出分布仍待复核。

## 下载与安装

支持 Windows 10 / 11 x64，需要 Microsoft Edge WebView2 Runtime。

- `velo-launcher.exe`：免安装版，先从托盘完全退出旧版，再替换原程序。
- `velo-launcher-amd64-installer.exe`：安装包。
- `SHA256SUMS.txt`：发布文件的 SHA-256 校验值。

设置、应用库、历史及缓存继续保存在 `%LOCALAPPDATA%\Velo`，软件界面为简体中文。发布文件暂未签名。

## 验证与发布产物

本地 `verify.ps1 -SkipBuild`、26 项前端测试、Go vet / 全部 Go 测试、`go test -tags latencyprobe ./...` 以及独立 Windows x64 生产构建均通过。新增 Win32 回归在焦点修复前失败、修复后通过。

正式下载文件取自该版本标签的 Windows CI，包含 exe、NSIS 安装包和校验清单；CI 链接与最终 SHA-256 随发布记录补充。
