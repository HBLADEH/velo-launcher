# Velo v0.12.0

Velo 0.12 带来可选的径向工作台，统一确认弹窗，并改进首页和搜索结果的鼠标操作。

## 工作台（测试功能）

- 在「设置 → 工作台」启用。可以指定鼠标前进键、后退键或快捷键作为触发方式。工作台默认关闭。
- 短按侧键打开完整菜单。长按后向上或向下划，分别选择全局动作和当前应用的动作，松开即可执行。
- 可为全局、默认和指定应用分别编辑布局。布局和触发设置保存在本机，并随配置备份。

## 启动器

- 移除失效应用、清空预览、启动组合、更新安装和系统操作的确认弹窗跟随 Velo 的浅色与深色主题。失效应用弹窗显示名称和操作影响，可保留固定、取消固定或移除自定义记录。 [Issue #16](https://github.com/HBLADEH/velo-launcher/issues/16)
- 首页打开时聚焦搜索框。悬停应用或按方向键可选中。点击空白处取消选中，搜索词保留。输入新查询后默认选中首条结果。
- 指针移到星标上时，卡片高亮和星标位置保持稳定。点击星标切换固定状态。
- 系统快捷优先显示 Windows 原生图标，并改进首页卡片、底栏和快捷方式名称的显示。

## 安装与升级

- Windows 10/11 x64 默认使用 `velo-rust-x64-installer.exe`。FemtoVG / OpenGL 替代构建使用 `velo-rust-femtovg-x64-installer.exe`。
- `velo-launcher-amd64-installer.exe` 与默认 Software 安装器字节一致，供旧版更新器使用。
- 升级前从托盘退出 Velo。数据继续保存在 `%LOCALAPPDATA%\Velo`，卸载时保留数据与恢复档案。
- 安装包暂未签名。可使用随版本发布的 `SHA256SUMS.txt` 核对文件，发行页同时提供构建清单和第三方许可。
