# Velo v0.11.0

本版加入默认关闭的 Everything 文件搜索和启动组合，整理为根目录的 Rust + Slint 工程。

## 用户变化

- 在设置 → 搜索启用 Everything，保存后按 Tab 在应用与文件搜索间切换；需要用户安装并运行默认 Everything 实例。
- 支持文件与文件夹、Everything 语法、显式分页、Enter 打开、Ctrl+Enter 定位和复制完整路径。隐藏后重新呼出或从设置返回时，恢复已加载的页数和选中的文件。
- 启动组合从带图标的应用库拖入成员，搜索组合名称批量启动，跳过已运行成员；保留失败项的重试能力。
- 修复托盘显隐竞态及回收站确认焦点，沿用既有深浅主题与快捷键。

## 开发变化

Cargo、src、ui、tests、windows 和 licenses 全部位于根目录。Go/Wails/Vue 与迁移期动态 oracle 移出主线，旧版保留在 go 分支。测试使用已固化的合成用例和静态数据指纹，不需要 Go 或 Node。

新增 `scripts/run-preview.ps1 -Build` 和 `scripts/clean.ps1`，开发数据放在 `.dev-data/`，可以独立清理 target 编译缓存。历史验收记录保留其构建身份。

## 安装与验证

- `velo-rust-x64-installer.exe` 是推荐的 Software 系统安装器，`velo-rust-femtovg-x64-installer.exe` 是 FemtoVG 替代安装器。
- `velo-launcher-amd64-installer.exe` 与 Software 安装器的字节相同，供旧版更新器使用。旧 Go v0.9.11 用户可参阅 [v0.10.0 迁移说明](https://github.com/HBLADEH/velo-launcher/releases/tag/v0.10.0)。
- 安装包适用于 Windows 10/11 x64，当前为未签名版本。升级前请从托盘退出 Velo。`SHA256SUMS.txt` 提供校验值，第三方许可和构建身份随安装器发布。

正式数据仍为 `%LOCALAPPDATA%\Velo`，新安装默认 Alt+Space。升级前备份和故障回滚沿用既有流程。Windows 11 x64 的构建与桌面验证记录随源码提供，机器验收范围以相应记录为准。[验证记录](https://github.com/HBLADEH/velo-launcher/blob/v0.11.0/docs/baselines/README.md)
