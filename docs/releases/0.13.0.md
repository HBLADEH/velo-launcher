# Velo v0.13.0

Velo 0.13 更新了工作台。启动组合也可以固定到首页，并随使用频率进入「常用项目」。

## 工作台（测试版）

- 新安装默认关闭工作台。可在「设置 → 工作台 → 通用」勾选「启用工作台」，选择鼠标侧键和备用快捷键。
- 短按侧键打开双区矩阵，上区显示全局动作，下区显示鼠标指针下应用的动作。可用备用快捷键打开同一界面。
- 长按侧键打开快捷盘，划向已绑定的方向后松手执行。动作按触发时的前台应用选取。
- 动作库支持文本、快捷键步骤、本地批处理、文件和网页。升级后，旧圆盘的槽位按原顺序迁入矩阵，手势方向可在设置中分配。首次保存新版工作台设置前会备份旧配置。

## 启动组合

- 在组合列表或搜索结果点击星标，可把整组置顶到首页「已固定」。
- Velo 记录整组启动的使用次数和时间，未置顶的组合随使用记录参与「常用项目」排序。

## 安装与升级

- Windows 10/11 x64 默认安装包为 `velo-rust-x64-installer.exe`。FemtoVG / OpenGL 构建使用 `velo-rust-femtovg-x64-installer.exe`。旧版更新器使用与默认安装包字节一致的 `velo-launcher-amd64-installer.exe`。
- 升级前从托盘退出 Velo。安装包暂未签名，可使用发行附件中的 `SHA256SUMS.txt` 核对文件。
