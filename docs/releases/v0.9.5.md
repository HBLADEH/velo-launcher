# Velo v0.9.5

本次预览版增加常用系统操作，改善呼出后的输入焦点与搜索匹配。

## 更新内容

- 新增清空回收站、关机、重启和锁屏，可直接搜索或固定到首页。清空回收站保留 Windows 确认提示，关机与重启先确认且不强制关闭应用。开机启动继续使用现有设置入口。
- 呼出主页时立即聚焦搜索框，不再等待索引读取；从设置或自定义应用面板返回后恢复输入焦点。
- 设置 → 快捷键新增“全屏时禁止快捷键呼出”，默认关闭。启用后，前台应用全屏时不通过快捷键打开主页，托盘入口仍可用；支持副屏和负坐标显示器。
- 名称、关键词和别名均支持中间匹配，关闭模糊搜索时同样生效；完整名称和前缀匹配仍优先。

## 下载与安装

支持 Windows 10 / 11 x64，需要 Microsoft Edge WebView2 Runtime。

- `velo-launcher.exe`：免安装版，退出 Velo 后替换原程序。
- `velo-launcher-amd64-installer.exe`：安装包。
- `SHA256SUMS.txt`：发布文件的 SHA-256 校验值。

两种方式均使用 `%LOCALAPPDATA%\Velo` 保存设置与缓存。可在“设置 → 关于”中检查更新。

## 验证与限制

验证覆盖格式检查、Wails 绑定生成、前端 lint / 类型检查 / 按键解析测试 / 构建、go vet 和 Go 测试；新增测试覆盖中间匹配、排序、系统操作白名单及多显示器全屏边界。

未在测试中实际执行关机、重启、锁屏或清空回收站。全屏应用兼容性与呼出焦点仍需更多实机验证。软件界面为简体中文，发布文件暂未签名，完整性能与长期稳定性验证仍在进行。
