# Velo v0.9.6

本次预览版新增搜索网格与候选项右键菜单，修复更新代理和 MuMu 搜索结果混入后台组件的问题。

## 更新内容

- **搜索网格**：在设置 → 外观中切换列表或网格，网格按应用与系统快捷分组展示，支持四个方向键导航；现有配置仍默认使用列表。
- **候选项右键菜单**：支持打开应用、打开安装目录、使用管理员权限打开、置顶 / 取消置顶；支持 `Shift+F10` 和键盘操作。不支持的操作自动禁用，管理员启动保留快捷方式参数与工作目录。
- **更准确的应用结果**：默认隐藏安装目录 `Hypervisor` 下直接扫描出的虚拟机后台组件，修复搜索 MuMu 时出现 Headless、NetNAT、Manage 等程序的问题。设备入口与模拟器入口仍分别保留，手动添加和固定的组件不受影响；关闭辅助项过滤可恢复结果。带编号等前缀的快捷方式名称也能按词首匹配，改善 `#0 MuMu安卓设备` 的排序。
- **更新代理**：版本检查、校验文件和程序下载支持 Windows 已启用的手动代理，优先使用相应协议的代理环境变量，并遵守代理例外及 `NO_PROXY`；切换代理后可直接重试。连接失败时提供网络与手动下载提示。

## 下载与安装

支持 Windows 10 / 11 x64，需要 Microsoft Edge WebView2 Runtime。

- `velo-launcher.exe`：免安装版，退出 Velo 后替换原程序。
- `velo-launcher-amd64-installer.exe`：安装包。
- `SHA256SUMS.txt`：发布文件的 SHA-256 校验值。

两种方式均使用 `%LOCALAPPDATA%\Velo` 保存设置与缓存，可在“设置 → 关于”中检查更新。若旧版受代理问题影响无法自动下载，请从本页手动下载安装包。

## 验证与限制

回归测试覆盖网格跨分组导航、布局配置兼容、菜单操作能力与管理员启动参数、代理选择与下载、MuMu 组件过滤和缓存切换。本机只读扫描确认 `mumu` 仅保留设备与模拟器两个应用入口。

自动代理脚本（PAC）和自动发现暂不支持。右键菜单与 UAC 的完整桌面交互仍需实机回归；未执行真实管理员启动或安装升级。软件界面为简体中文，发布文件暂未签名，完整性能与长期稳定性验证仍在进行。
