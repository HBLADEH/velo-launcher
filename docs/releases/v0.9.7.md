# Velo v0.9.7

本次预览版支持拖动 Launcher、隐藏后恢复原页面，并加入配置备份，修复更新过程中再次呼出导致进度丢失和重复下载的问题。

## 更新内容

- **窗口拖动**：拖动顶部标志、标题或空白区域移动窗口，首页、搜索页、设置和自定义应用页面均支持；搜索框和按钮仍可正常操作。当前会话内保留拖动位置，窗口变大或显示器断开时确保窗口仍在可见区域。
- **隐藏后继续原页面**：点击窗口外部只隐藏，再次呼出保留设置分类、未保存修改、搜索内容及更新进度。
- **更新不中断**：隐藏窗口后继续下载；主动离开设置再回来仍能查看进度，前后端都阻止重复启动更新。下载失败后可重试。
- **配置备份**：设置 → 备份可立即备份已保存设置、打开备份目录；每次生成独立 JSON 文件。安装更新前自动备份，失败则停止安装；更新后沿用已有配置，新选项在读取时补齐默认值。

## 下载与安装

支持 Windows 10 / 11 x64，需要 Microsoft Edge WebView2 Runtime。

- `velo-launcher.exe`：免安装版，完全退出 Velo 后替换原程序。
- `velo-launcher-amd64-installer.exe`：安装包。
- `SHA256SUMS.txt`：发布文件的 SHA-256 校验值。

设置与缓存仍保存在 `%LOCALAPPDATA%\Velo`，配置备份在其 `backups` 子目录中。备份仅包含已保存的 `config.json` 设置，不含自定义应用、固定项或历史记录；恢复说明见用户指南。

## 验证与限制

回归测试覆盖拖动位置在窗口尺寸变化和屏幕布局变化后的约束、更新请求去重及失败重试、备份内容一致性、更新前备份失败中止，以及旧配置读取后不被改写。

本地前端 lint、类型检查、7 项前端测试、Go vet 和全部 Go 测试通过。隔离桌面测试确认设置页与受控下载进度正常显示；拖动及失焦后再次呼出的完整桌面交互回归尚未完成。

窗口位置和隐藏的页面状态仅在当前运行期间保留，完全退出后从首页开始。软件界面为简体中文，发布文件暂未签名，完整性能与长期稳定性验证仍在进行。
