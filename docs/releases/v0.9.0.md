# Velo v0.9.0

预览版（prerelease）。本版新增**自动更新**与**自定义应用库**（添加 / 删除搜索范围外的应用）。

## 新增功能

### 自动更新

- 启动后自动检查 GitHub 发布页，发现新版本时窗口底部显示版本按钮；设置 → 关于 可手动检查或关闭自动检查。
- 设置 → 关于 显示当前版本、发布说明、下载进度，并提供“下载并安装”。
- 独立程序：下载新的 `velo-launcher.exe`，退出后由独立脚本原地替换并自动重新启动。
- 安装版：安装在 Program Files 时改用安装包静默升级，Windows 会提示 UAC 确认。
- 下载内容使用本次发布的 `SHA256SUMS.txt` 校验；校验文件缺失或校验不一致时停止自动安装，只保留手动下载。
- 自动检查只读取发布页的版本信息，不上传任何本机数据，也不会在后台静默替换程序。

### 自定义应用库

- 入口：首页“＋ 自定义应用”、窗口底部“自定义应用”，或设置 → 索引 → 管理自定义应用。
- 支持拖入多个 `.exe` / `.lnk`、使用文件选择对话框，或粘贴完整路径；列表内可逐项删除。
- 添加后立即可搜索，刷新索引或重启 Velo 后仍然保留；删除只移除自定义记录与首页固定，不删除原程序文件。
- 自定义应用与首页固定统一保存在 `application-library.json`；旧版 `quick-launch.json` 的手动条目会自动迁移，原文件保留为备份。
