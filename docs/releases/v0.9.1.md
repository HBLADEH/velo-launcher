# Velo v0.9.1

本次预览版优化启动台界面、主题显示与搜索交互。

- 更新首页、搜索结果及设置面板样式，统一使用本地打包的 Microsoft Fluent UI System Icons，并提供开源许可说明。
- 改善浅色、深色和跟随系统主题的背景同步，减少启动与再次呼出时的背景闪烁；没有固定应用时不再显示空的固定分组。
- 点击主页面内其他区域时，搜索框保持焦点；返回主页面后自动恢复输入焦点。
- 搜索框有内容时，按 Esc 清空输入并回到主页；输入为空时按 Esc 隐藏窗口。底部提示随输入状态切换。
- 补充系统快捷入口的英文名称、拼音和缩写，例如 calculator、rwglq、hjbl；入口无需固定即可检索，取消固定后仍可搜索。

## 下载

- `velo-launcher.exe`：Windows x64 独立程序。
- `velo-launcher-amd64-installer.exe`：Windows x64 安装包。
- `SHA256SUMS.txt`：上述产物的 SHA-256 校验值，供手动校验与应用内自动更新使用。

需要 Windows 10 / 11 x64 和 Microsoft Edge WebView2 Runtime。此版本仍为预览版，发布文件未签名。

原生窗口焦点、主题切换及安装后的完整自动更新流程仍需人工回归。
