# Velo v0.13.1

Velo 现在可以搜索、启动和固定 Windows `.url` 快捷方式，包括 Steam 游戏和网页链接。 [Issue #20](https://github.com/HBLADEH/velo-launcher/issues/20)

- 刷新索引后，桌面、开始菜单和自定义扫描目录中的 `.url` 文件会按名称进入搜索结果。
- 「自定义项目」支持拖入、选择文件或粘贴 `.url` 文件路径。同一个文件通过扫描和手动导入添加时，搜索结果只显示一项。
- 按 `Enter` 通过 Windows 打开快捷方式。网页使用默认浏览器，Steam 游戏使用已注册的 Steam 协议。右键可以打开快捷方式所在目录。
- 把 Steam 游戏快捷方式加入启动组合后，可指定游戏实际运行的 `.exe` 供组合检查运行状态。

## 安装与升级

- Windows 10/11 x64 默认使用 `velo-rust-x64-installer.exe`。FemtoVG / OpenGL 使用 `velo-rust-femtovg-x64-installer.exe`。旧版更新器使用与默认安装包字节一致的 `velo-launcher-amd64-installer.exe`。
- 升级前从托盘退出 Velo。安装包暂未签名，可用发行附件中的 `SHA256SUMS.txt` 校验。
