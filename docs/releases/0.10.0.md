# Velo v0.10.0

Velo 已切换为 Rust + Slint 原生应用，继续沿用 Go 0.9.x 的版本顺序。Go/Wails 版本停止维护，请迁移到本版；Rust 0.1.0 用户也可直接更新。

## Go 版本用户请先看这里

- **官方 Go v0.9.11 系统安装版**：在“设置 → 关于”检查更新，阅读本说明后点击下载安装。正常以普通权限运行、Program Files 安装目录不可写时，旧更新器会下载默认 Software 兼容包、校验 SHA-256、备份配置，再请求 UAC 进行原位升级。也可退出托盘后手动运行默认安装器。
- **免安装版、管理员运行或安装目录可写**：请先从托盘退出旧 Velo，再手动下载并运行 `velo-rust-x64-installer.exe`。旧免安装更新器只会替换单个 exe，本次不提供该自动迁移路径；请勿在旧版中点击“下载并安装”。
- **其他旧系统安装版本或自行编译版**：先退出并卸载旧程序，保留用户数据，再安装本版。原位接管仅限已核对 SHA-256 的官方 Go v0.9.11。
- **Rust 0.1.0**：可使用关于页下载并安装，会保持当前渲染器。

新安装默认按 **Alt+Space** 呼出；迁移保留你原来设置的快捷键。

设置、历史、自定义应用和固定项继续存放在 `%LOCALAPPDATA%\Velo`。首次打开数据前，会在同级 `%LOCALAPPDATA%\VeloRustMigrationBackups` 保留原始数据快照；备份失败会停止初始化。安装失败保留旧状态，安装目录的 `.velo-rollback` 保留程序恢复档案。有原始 Go 快照时，可退出 Velo 后运行 `uninstall.exe /ROLLBACK` 恢复旧程序；卸载和回退保留用户数据。

## 本版变化

- 窗口标题、托盘提示和 Windows 应用名称统一为 **Velo**。
- 单击托盘图标切换显示与隐藏，继续保留当前页面和设置草稿。右键“打开 Velo”始终打开。
- 修复主页面右下角提示错位、空格启动提示与“自定义应用”重叠。
- Space 使用与方向键一致的按键框，位于回车右侧，共用“启动”提示；关闭空格启动后自动隐藏。
- 延续拼音与模糊搜索、应用索引、固定与常用应用、自定义应用、主题、快捷键、托盘、配置备份，以及 SHA-256 校验更新。

## 下载文件

- `velo-rust-x64-installer.exe`：默认 Software 系统安装版，推荐下载。
- `velo-launcher-amd64-installer.exe`：同一个 Software 安装器的相同字节副本，兼容旧 Go 更新器，二选一即可。
- `velo-rust-femtovg-x64-installer.exe`：FemtoVG / OpenGL 替代构建。切换前完全退出 Velo。
- `SHA256SUMS.txt`：校验值；`velo-rust-0.10.0-licenses.zip`：第三方许可；`release-manifest.json`：构建身份。

Windows 10/11 x64。本次提供系统安装包，无独立免安装版；安装时需要 UAC。安装包尚未签名，Windows 可能显示未知发布者。两种渲染器存在资源与帧节奏取舍，不承诺所有设备达到统一内存预算。
