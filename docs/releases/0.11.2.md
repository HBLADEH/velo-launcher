# Velo v0.11.2

本版支持固定文件夹，并改进应用内更新日志和下载进度展示。

## 用户变化

- 在“自定义项目”中选择、拖入或粘贴文件夹路径，导入后可固定到首页、搜索并打开。
- 在 Everything 文件搜索结果中右键文件夹，可直接固定或取消固定；固定记录会保存到本地应用库。
- 更新日志保留标题、列表和链接文字的连续排版，减少断行与多余空白。
- 下载更新时显示进度条和已下载数据量；服务器提供总大小时同时显示百分比，完成后显示校验与配置备份状态。

## 安装与数据

- Windows 10/11 x64 默认使用 `velo-rust-x64-installer.exe`；`velo-rust-femtovg-x64-installer.exe` 为 FemtoVG / OpenGL 替代构建。
- `velo-launcher-amd64-installer.exe` 与默认 Software 安装器字节相同，供旧版更新器使用。
- 升级前请从托盘退出 Velo。用户数据继续保存在 `%LOCALAPPDATA%\Velo`，卸载保留数据及恢复档案。
- 安装包暂未签名。请使用随版本发布的 `SHA256SUMS.txt` 核对文件；第三方许可和构建身份一并提供。

双渲染器通过 Windows 11 x64 本机完整检查与桌面冒烟；发行安装包由 GitHub Actions 在版本标签上构建并核对 SHA-256 后发布。Windows 10、真实 IME 和系统安装事务的覆盖以各自历史构建记录为准。[本版验证记录](https://github.com/HBLADEH/velo-launcher/blob/v0.11.2/docs/baselines/2026-11-20-v0.11.2/README.md)
