性能门槛：1000 应用搜索 <10ms；冷启动 <500ms（目标 300ms）；热呼出 <50ms；空闲 CPU 接近 0%；总常驻内存目标 <80MB。测量必须说明进程范围、环境与方法。

当前达成情况：搜索已达标；冷启动仅有单次 470/523 ms 记录，热呼出未测量，空闲 CPU 与内存未达标。口径与数据见 [验证记录](verification.md)。
